# Architecture Decision Records

ADRs capture significant technical decisions and the reasoning behind them.

- `0001-record-architecture-decisions.md` — why this project uses ADRs.
- `template.md` — copy this file for a new ADR.

## Creating an ADR

1. Copy `template.md` to `NNNN-short-title.md` using the next number.
2. Fill in Context, Decision, and Consequences.
3. Set Status to `Proposed` until the team accepts it.
4. Link related ADRs instead of editing accepted ones.
